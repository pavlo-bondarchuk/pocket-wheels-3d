# Pocket Wheels 3D

Легкий браузерний 3D-прототип у стилі die-cast racing.

## Що вже є

- 40 процедурних машинок у 10 класах
- 3D-траса з вертикальною петлею, трампліном, бустами та огородженнями
- 5 AI-суперників
- 2 кола, позиція, таймер, швидкість, фінішний екран
- гараж з вибором усіх 40 машин
- 3 режими камери
- клавіатура та touch-керування
- AUTO / LOW / MED / HIGH якість
- без важких GLB/FBX моделей та без текстурних пакетів

## Запуск

Варіант 1:

```bash
python3 -m http.server 8080
```

Після цього відкрити `http://localhost:8080`.

Варіант 2: задеплоїти папку як статичний сайт на GitHub Pages, Cloudflare Pages, Netlify або Vercel.

## Керування

- W / ↑ — газ
- S / ↓ — гальмо
- A D / ← → — зміщення по треку
- C — камера
- R — рестарт
- G — гараж

## Архітектура

Рендер: Three.js.

Фізика: lightweight arcade spline physics. Машина прив'язана до 3D-профілю треку, тому петлі та складні вертикальні секції працюють стабільно навіть на слабких пристроях.

Машинки не є копіями ліцензованих моделей. Усі форми та назви вигадані. Для точних Hot Wheels моделей можна підмінити процедурні кузови на оптимізовані GLB, якщо є право використовувати такі ассети.
